Audio assets expected by the sound system (SoundManager.ts, useUISound.ts,
useMenuMusic.ts, ResultScreen.tsx). Every play call is guarded (SoundManager
checks cache.audio.exists(); domAudio's playDomSound() catches the play()
rejection), so a missing file is a silent no-op, not a crash -- add a file
at the path below and it starts playing with no code changes.

Named .txt (not .md) on purpose: this repo's .gitignore has a blanket *.md
rule, so a .md file here would never get committed.

IMPORTANT: assets go in client/public/assets/audio/, NOT client/dist/. dist/
is vite build OUTPUT -- it's gitignored, gets wiped and regenerated by
`vite build`, and isn't served in dev at all. public/ is the real source
location (this is the same public/assets/sprites/ pattern the sprite packs
already use).

Suggested free sources for anything still missing below: jsfxr/Bfxr
(generate 8-bit SFX yourself -- fits this game's retro-pixel look),
Kenney.nl (CC0 UI Audio / Impact Sounds packs), OpenGameArt.org (filter by
license).
